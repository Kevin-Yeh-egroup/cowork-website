# 好理家在新版平台 IT 規格補充 v2

更新日期：2026/07/24

## 0. 文件使用原則

畫面呈現請以新版草稿網站為主，本文件只補充畫面上看不出來、但 IT 開發需要知道的規格。

本文件不重複描述：

- 頁面標題
- 區塊順序
- 卡片文字
- 按鈕位置
- 已在頁面中呈現的說明文字

本文件補充：

- 按鈕點擊後行為
- 欄位資料格式
- 資料來源
- 儲存位置
- 跨工具資料連動
- 外部連結規則
- 後台或通知流程
- 另需提供的對應表

## 1. 全站共通

### 1.1 導覽與手機選單

1. 上方導覽新增「網站導覽」。
2. 網站導覽連結至：https://www.familyfinhealth.com/sitemap
3. 手機版三橫線選單需可開啟、關閉、展開子分類，並可正常捲動。
4. 外部連結需另開視窗。

### 1.2 登入與資料保存

1. 外層工具可未登入使用。
2. 未登入資料可暫存在瀏覽器本機。
3. 未登入資料不跨裝置、不跨瀏覽器。
4. 使用者點選「儲存」時，若尚未登入，需導向登入頁。
5. 登入後資料保存至會員帳號。
6. 已保存資料需可在「我的財務與生活」查看或修改。

### 1.3 共用按鈕規則

| 按鈕 | 行為 |
|---|---|
| 儲存 | 未登入導向登入；登入後保存資料 |
| 查看／修改 | 回到資料來源工具，或開啟對應編輯視窗 |
| 下載 PDF | 匯出目前報表 |
| 下載 Excel | 匯出目前報表 |
| 列印 | 開啟列印 |
| 官方試算 | 另開視窗至官方網站 |

## 2. 免費諮詢

頁面路徑：`/online-consultation`

### 2.1 申請流程

需確認並實作：

1. 表單送出後資料儲存位置。
2. 是否建立後台查看申請資料。
3. 是否寄送通知信給內部人員。
4. 是否寄送確認信給申請者。
5. 是否需要登入才能申請。
6. 申請成功後顯示頁或提示文字。

### 2.2 社工轉介申請

1. 「我想協助個案或家庭申請」不放在免費諮詢頁。

### 3.2 記帳助理

頁面路徑：`/toolbox/accounting`

#### 3.2.1 帳本模式

需支援：

- 個人帳
- 公司帳

個人帳與公司帳的類別需分開。

#### 3.2.2 收支模式

個人帳：

- 收入
- 支出
- 儲蓄

公司帳：

- 營業收入
- 營業支出

#### 3.2.3 欄位

| 欄位 | 規格 |
|---|---|
| 日期 | 預設今天，可修改 |
| 類別 | 下拉選單 |
| 金額 | 數字欄位 |
| 付款／收款方式 | 下拉選單 |
| 發生頻率 | 下拉選單 |
| 備註 | 文字欄位 |

#### 3.2.4 類別說明

1. 使用者切換類別時，下方說明文字需同步更新。
2. 不可出現類別與說明不一致的狀況。
3. 給 IT 的分類對照表不得顯示在使用者頁面上。

#### 3.2.5 與財務月報表對應

| 記帳資料 | 帶入月報表 |
|---|---|
| 個人帳收入 | 個人收入／家庭生活收入 |
| 個人帳支出 | 生活支出 |
| 儲蓄 | 儲蓄與目標準備 |
| 公司帳營業收入 | 公司帳收入 |
| 公司帳營業支出 | 公司帳支出 |

#### 3.2.6 語音輸入

需支援語音輸入。

解析範例：

使用者說：「今天早餐 80 元，用現金付」

系統解析：

- 日期：今天
- 類型：支出
- 類別：食
- 金額：80
- 付款方式：現金

#### 3.2.7 紀錄管理

登入後需支援：

- 查看紀錄
- 修改紀錄
- 刪除紀錄
- 同步至我的財務與生活

### 3.3 財務月報表

頁面路徑：

- 外層：`/toolbox/monthly-report`
- 登入後：`/personal-center#member-monthly-report`

#### 3.3.1 外層與登入後差異

外層只提供月報。

登入後提供：

- 月報
- 半年報
- 年報
- 歷史紀錄
- PDF 下載
- Excel 下載
- 列印

#### 3.3.2 報表模式

需支援：

- 家庭
- 個人
- 公司帳

切換後，頁面資料與欄位標題需同步切換。

#### 3.3.3 公司帳規則

公司帳收入與支出只在公司帳檢視呈現，不混入家庭或個人報表。

此規則為資料邏輯，不需在使用者頁面顯示說明文字。

#### 3.3.4 月報表資料區塊

需包含：

- 收入
- 生活支出
- 債務還款
- 儲蓄與目標準備
- 資產
- 負債
- 報表摘要

#### 3.3.5 生活支出、債務還款、儲蓄

三者在月報表中需分開呈現。

| 區塊 | 定義 |
|---|---|
| 生活支出 | 日常生活花掉的錢 |
| 債務還款 | 用來降低負債或維持還款的金額 |
| 儲蓄與目標準備 | 留給未來或特定目標的錢 |

#### 3.3.6 資產

資產不另開獨立工具，於財務月報表管理。

預設資產項目：

- 現金
- 活存／薪轉帳戶
- 定存
- 保單價值／儲蓄險
- 投資現值
- 房屋／土地
- 汽機車估值
- 互助會活會
- 其他資產

規格：

1. 預設項目一開始即列出。
2. 未填寫時金額顯示 0。
3. 每列皆顯示「修改」。
4. 點選「修改」後開啟小視窗，可輸入或修改該項金額。
5. 若要新增預設項目之外的資產，才使用「新增資產項目」。

#### 3.3.7 負債

1. 負債資料主要由債務盤點表帶入。
2. 月報表中負債的「修改」需連至債務盤點表。
3. 不應連到信用卡、信貸、車貸等單一計算工具。

#### 3.3.8 資料來源

使用者頁面不顯示「資料來源」字樣。

資料對應：

| 月報表欄位 | 資料來源 |
|---|---|
| 收入 | 記帳助理 |
| 生活支出 | 記帳助理 |
| 債務還款 | 債務盤點表 |
| 儲蓄與目標準備 | 記帳助理、生活目標財務規劃 |
| 資產 | 月報表資產區 |
| 負債 | 債務盤點表 |

### 3.4 財務健康安全儀表板

頁面路徑：`/toolbox/financial-health-dashboard`

#### 3.4.1 使用方式

需支援：

1. 從財務月報表帶入完整資料後查看。
2. 使用者先輸入粗略數字或語音輸入，取得初步結果。

#### 3.4.2 初步檢視與完整檢視

| 狀態 | 行為 |
|---|---|
| 初步檢視 | 外層可使用，粗略輸入即可產出初步結果 |
| 完整檢視 | 引導登入，回到我的財務與生活補齊資料 |

#### 3.4.3 指標

需評估的指標：

- 月收支平衡
- 年收支平衡
- 資產負債比
- 被動收入
- 緊急預備金
- 保險保障
- 未來財務規劃
- 信用或債務壓力狀況

#### 3.4.4 連動頁面

儀表板需能引導回：

- 記帳助理
- 財務月報表
- 債務盤點表
- 生活目標財務規劃

### 3.5 債務盤點表

以下功能整合為同一流程：

- 債務盤點表

| 開辦費／手續費 | 數字 |
| 年利率 | 數字 |
| 利率或免息說明 | 下拉，可自行輸入 |
| 還款期數 | 下拉，可自行輸入 |
| 約定還款頻率 | 下拉 |
| 每期還款金額 | 數字 |
| 還款期限 | 日期或文字 |
| 還款狀況 | 下拉 |

若下拉選單包含「自行輸入」，點選後需出現文字輸入框。

此文章底部已有示意延伸區塊，IT 開發時需注意：

1. 文章底部不只顯示延伸閱讀，也需可放延伸問答、相關工具、相關生活情境或諮詢入口。

3. 不建議所有文章都使用完全相同 CTA。
4. 每篇文章至少需支援設定：

   - 相關工具
   - 相關生活情境

5. 若文章未設定特定 CTA，可使用預設延伸閱讀。

### 12.1 名詞與網址對應表

此表建議另開一份檔案整理，不放在本規格書內。

需包含：

- 現行網站名稱
- 新版名稱
- 現行網址
- 新版網址
- 是否保留原網址
- 是否為外部連結
- 備註
