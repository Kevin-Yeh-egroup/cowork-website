## 使用說明

本表用來協助 IT 對照「現行正式網站」與「新版草稿網站」的頁面名稱、網址與處理方式。

欄位說明：

- 頁面／功能：表格辨識用，不一定是網站實際顯示文字。
- 現行網站顯示名稱：目前正式網站上可看到的名稱；若現行網站沒有，填「無」。
- 新版草稿顯示名稱：新版草稿頁面預計顯示的名稱。
- 現行網址：目前正式網站使用的網址；若現行網站沒有，填「無」。
- 新版網址：新版草稿或正式預計使用的網址。
- 處理方式：保留、名稱調整、大幅改版／功能重組、新版新增、整併、外部連結、待確認。
- 備註：需要 IT 注意的導向、資料或權責說明。

注意：

1. 網址不一定等於頁面顯示名稱。
2. 「生活課題」與「服務對象」屬新版新增資訊架構，現行網站沒有完全對應頁面。
3. 「我的財務與生活」不是現行個人中心單純改名，而是大幅改版與功能重組。
4. 現行網址仍需由 IT 或同事做最後核對。
